缺陷检测课程 · 第 12 课

零样本时代:CLIP 与大模型

一张训练样本都没有,靠一句话描述就能检缺陷——语言先验如何改写这个领域的游戏规则。

0 快速回顾

第 7 到第 11 课,我们把无监督缺陷检测的四大家族走了一遍:重构类(第 7 课)、特征嵌入类(第 8 课)、师生蒸馏类(第 9 课)、合成缺陷类(第 10 课)、归一化流类(第 11 课)。它们的思路各不相同,但有一个共同的地基:都需要一批正常样本来"学什么是正常"——建重构器、建 memory bank、教学生网络、估概率密度,原料全是正常图。

现实里恰恰有一类场景,连这点原料都凑不齐:

  • 新产线冷启动:产线今天刚投产,一张历史图像都没有,但质检明天就要上线;
  • 多品种小批量:一条产线轮着做几十种零件,每种只跑几百件——为每个品种单独攒数据、训模型、调阈值,成本算不过来。

可是想想人类质检员:新员工第一天上岗,没见过这条产线的任何样品,也能挑出明显的缺陷。为什么?因为他带着语言先验——"划痕是细长的暗线"、"凹坑是局部的凹陷"、"完好的表面应该均匀光洁"。这些知识不来自这条产线,来自他一辈子的语言和视觉经验。

本课要做的事,就是把这种先验搬给模型:让模型听懂"划痕"这个词,然后用一句话代替一批训练样本。故事从 2021 年的 CLIP 开始。

1 CLIP 原子拆解:图和文住进同一个空间

CLIP(Contrastive Language-Image Pre-training,OpenAI,2021)要解决的问题听起来很朴素:让一张图和一句话可以直接比相似度。图是像素,话是字符,它们原本住在两个毫不相干的世界里——CLIP 用一个训练目标把它们搬进了同一个向量空间。

双塔结构:两个编码器,一个空间

CLIP 由两座"塔"组成:一个图像编码器(ResNet 或 ViT)把图像映成一个向量,一个文本编码器(Transformer)把句子映成一个向量。关键设计是:两个向量维度相同(例如 512 维),且都做 L2 归一化——于是任意一张图和任意一句话之间,都可以算余弦相似度:

图像 ──→ [ 图像编码器 ] ──→ 图像向量 v ─┐ ├──→ 相似度 = cos(v, t) = v·t 文本 ──→ [ 文本编码器 ] ──→ 文本向量 t ─┘ # 两个向量同在一个 512 维空间,都已 L2 归一化,余弦 = 点积

回忆第 8 课:我们在特征空间里用距离衡量"这个 patch 正常不正常"。CLIP 做的是同一件事的跨模态版——只是现在,空间里既有图、也有话。

训练目标:4 亿图文对上的"连连看"

怎么把两座塔训练到"说到一起去"?CLIP 从互联网收集了约 4 亿对(图像, 描述文字),用对比学习训练:配对的(图, 文)在空间里拉近,错配的推远。具体做法是,每个 batch 取 N 对图文,算出 N×N 的相似度矩阵——对角线上是真正配对的正样本,其余全是错配的负样本:

文本1 文本2 文本3 文本4 图像1 ★0.9 0.2 0.1 0.3 ★ = 配对 → 拉近 图像2 0.1 ★0.8 0.2 0.2 其余 = 错配 → 推远 图像3 0.3 0.1 ★0.9 0.1 图像4 0.2 0.3 0.2 ★0.7 # InfoNCE 损失:对每一行(和每一列)做 softmax + 交叉熵, # 目标 = 让对角线的概率最大 —— 一场 batch 内的"连连看"

这个损失函数叫 InfoNCE,拆开看一点都不神秘:对矩阵的每一行做 softmax,把"图像 i 配文本 i"当成正确类别算交叉熵——正是第 1 课的老朋友,只是"类别"换成了"batch 里的哪句话"。再回忆第 10 课的自监督:这里同样没有人工标注,"哪张图配哪句话"这个配对关系本身就是免费的监督信号。

4 亿对数据练完,奇迹发生了:图像和文字第一次"住进"了同一个语义空间。"一张猫的照片"这句话的向量,就落在猫图片向量的旁边;"划痕"这个词的向量,离带划痕的图像更近。相似度 = 余弦,跨模态检索、比对,一把尺子量到底。

zero-shot 分类:分类器是"写"出来的

这个空间最惊人的用法,是不训练任何东西就做分类。想分猫/狗/飞机?把每个类别写成一句 prompt,过一遍文本编码器:

prompts = ["a photo of a cat", "a photo of a dog", "a photo of a plane"] # 文本编码器 → 3 个文本向量,它们就是 3 个"类别中心" # 新图像 → 图像编码器 → 图像向量 # 看图像向量和哪句话的余弦最大 → softmax → 分类完成

传统分类器的权重要靠标注数据训出来;这里,每句 prompt 的文本向量直接充当了分类器的权重。想换类别?改字符串就行,一秒生效。这就是 zero-shot(零样本)分类:对目标任务零训练样本、零训练过程。

范式转变

过去:定类别 → 采数据 → 标标签 → 训模型 → 才有分类器。
现在:分类器 = 一组句子。对缺陷检测,这意味着"正常 / 划痕 / 凹坑 / 污染"也可以只是四句话——不需要缺陷样本,甚至不需要正常样本。下一节亲手玩一遍。

2 亲手玩:图文匹配模拟器

空说不如上手。下面是一个"纸上 CLIP":左边 4 张程序生成的金属盘工件图,右边 4 句文本 prompt。内置的 4×4 相似度矩阵取自真实 CLIP 的典型量级(余弦约 0.2~0.35,配对的最高)。点一张图,看它和每句话的相似度,以及 softmax 之后的分类概率:

🔍 交互:点一张图,让四句话来"认领"它
依次点 4 张图,观察两件事:① 蓝色相似度条的差距其实不大(0.21 vs 0.33 的量级);② softmax(除以温度 τ=0.05 再归一)把这点差距放大成了悬殊的概率,最高的一句高亮为橙色。这 4 张图没有参与过任何训练——分类它们的,是右边那四句话。
「一张完好金属零件的照片」—
「一张带划痕的金属零件照片」—
「一张有凹坑的金属零件照片」—
「一张被污染的金属零件照片」—
点击左侧任意一张工件图。

注意模拟器里的两个细节,它们都是真实 CLIP 的行为:

  • 没有一条相似度是 0:四句话都提到"金属零件",语义本来就重叠。CLIP 的余弦从不给出干脆的 0/1,决策靠的是相对大小;
  • 温度把小差距放大成大概率:softmax 前把相似度除以一个小温度(真实 CLIP 用约 1/100),0.1 的余弦差距就能变成 50 个百分点的概率差距。练习的 TODO 3 会让你亲手实现带温度的 softmax,感受"温度越低,分布越尖"。
这就是全部

刚才发生的事,就是 zero-shot 分类的全部:没有训练循环,没有梯度,没有标注——只有"问对问题"。四句话就是四个分类器;想识别新的缺陷类型,写第五句话就行。

3 用到缺陷检测:WinCLIP 的三板斧

把 zero-shot 分类搬进缺陷检测,第一个动脑筋的问题是:类别怎么定?缺陷千奇百怪,逐一列举不现实。WinCLIP(CVPR 2023)给出的答案朴素而有效:不列举缺陷,只对垒两个阵营——正常 vs 异常。

第一板斧:两组 prompt 对垒

为"正常"和"异常"各写一组 prompt,让图像在两个阵营之间"站队":

normal 组: "a photo of a flawless {object}" "a photo of a perfect {object}" "a photo of a {object} without defect" … anomaly 组: "a photo of a damaged {object}" "a photo of a {object} with a defect" "a photo of a broken {object}" … 异常分 = softmax( [sim_normal, sim_anomaly] / τ ) 里 anomaly 侧的概率 # {object} 填产品名:metal plate / cable / pill … # 异常分 ∈ (0,1),天然就是一个可设阈值的分数

这正是 §2 模拟器的两队版:图像和 normal 组、anomaly 组各算相似度,softmax 之后 anomaly 侧的占比就是异常分数。练习的 TODO 5 会让你实现一个两句话的最小版。

第二板斧:prompt ensemble,降低措辞敏感

为什么每组要写很多句而不是一句?因为 CLIP 对措辞敏感:"damaged"和"broken"在向量空间的位置不同,单句 prompt 的分数会随用词波动。WinCLIP 的做法是状态词 × 句式模板做组合,把每组几十句话的文本向量取平均,再拿平均向量去比——多句话互相抵消各自的偏差,分数稳定得多。这招叫 prompt ensemble(集成),成本几乎为零,是所有 CLIP 系方法的标配。

第三板斧:窗口化,从"有没有"到"在哪里"

整图和文本比相似度,只能回答图像级的"有没有缺陷"。可是第 4 课就讲过,工业质检往往还要"在哪里"。WinCLIP 的解法回收了第 8 课的 patch 思想:把图像切成多尺度的滑动窗口,每个窗口单独和两组文本对垒打分,再把各尺度的分数图对齐、聚合,就得到一张粗定位热力图:

STEP 1
多尺度滑窗
小 / 中 / 大窗口
扫过整张图
→
STEP 2
逐窗对垒
每个窗口和 normal /
anomaly 两组比相似度
→
STEP 3
聚合热力图
多尺度分数对齐取优
→ 粗定位缺陷区域

对照第 8 课:PatchCore 拿每个 patch 的特征去查"正常样本库"里的最近邻;WinCLIP 拿每个窗口的特征去问"两组话"哪边更像。套路没变,"库"换成了"话"——正常样本库需要采集数据才能建,两组话现在就能写出来。这就是零样本的全部代价与全部收益。

4 AnomalyCLIP:把 prompt 也交给学习

WinCLIP 好用,但用过的人很快会遇到两个烦恼,根源都在"prompt 是手写的":

  • 措辞敏感:"damaged"换成"broken",分数可能差一截;prompt ensemble 能缓解,不能根治。写 prompt 变成了一门碰运气的手艺;
  • 要为每类产品想词:金属件该说 scratch(划痕),布料该说 tear(破洞),药片该说 crack(裂纹)——产品一多,prompt 工程本身就成了新的人工成本,和"零样本省人力"的初衷背道而驰。

AnomalyCLIP(ICLR 2024)的解法直截了当:既然措辞难挑,就别挑了——把 prompt 变成可学习的向量。prompt 不再是英文单词序列,而是一串可以被梯度更新的嵌入向量(想象成"意义可调的假词"):

手写 prompt: "a photo of a damaged metal plate" # 词是死的,还绑定产品 可学习 prompt: [V1][V2]…[Vn] + "object" # V 是可训练向量 # 只学两条:一条代表"正常物体",一条代表"异常物体" # 不出现任何具体产品名 → object-agnostic(物体无关)

最关键的设计是 object-agnostic(物体无关):这两条 prompt 向量学的不是"正常的金属盘"或"异常的电缆",而是"正常"和"异常"这两个抽象概念本身。训练只需要在少量带标注的辅助数据上做一次(辅助数据来自其他产品、其他数据集),学到的"正常/异常"概念就能直接迁移:换一种从未见过的产品,不用重写 prompt、不用重新训练,拿来就用——对目标产品,依然是零样本。

WinCLIP:手写 prompt

零训练,开箱即用;

但措辞敏感,且要为每类产品设计 {object} 和状态词。

AnomalyCLIP:可学习 prompt

在辅助数据上训一次 prompt 向量(编码器全程冻结);

object-agnostic,跨产品零样本泛化,措辞问题从根上消失。

一句话总结这一步演化:WinCLIP 证明"话"能当分类器,AnomalyCLIP 证明这句"话"本身也可以被学出来——而且学的是放之四海皆准的"正常/异常"概念,不是某个产品的专属描述。

5 SAM 与分割精修:基础模型乐高

CLIP 系方法的热力图有个先天短板:滑窗打分,定位是"块状"的粗定位,缺陷的精确轮廓画不出来。而第 6 课讲过,有些场景需要像素级的缺陷面积、长度来判定是否超标。补上这块拼图的,是另一个基础模型:SAM。

SAM:万物分割

SAM(Segment Anything Model,Meta,2023)是分割界的"基础模型":在 1100 万张图像、11 亿个 mask 上训练,学会了一件通用的事——给一个提示(在图上点一个点,或框一个框),就把提示所指的物体精确抠出来。它不认识"划痕"、不知道"缺陷"是什么,但只要你指到那里,它就能沿着边界画出像素级的 mask,对没见过的物体照样有效。

组合拳:CLIP 找,SAM 抠

一个不知道缺陷在哪但能精确抠图的模型,和一个知道缺陷大概在哪但抠不准的模型——把它们拼起来,正好互补:

STEP 1
CLIP 系粗定位
WinCLIP / AnomalyCLIP
输出异常热力图
→
STEP 2
取峰值当提示
热力图最热的位置
变成一个提示点
→
STEP 3
SAM 精修
从提示点出发
抠出精确 mask
→
输出
像素级轮廓
缺陷面积 / 长度
可量化、可判超标

注意这个系统的工作方式:没有从头训练任何东西。CLIP 出"图文对齐打分"的能力,SAM 出"指哪抠哪"的能力,像乐高一样拼起来,就是一条完整的零样本检测 + 分割流水线。这种基础模型乐高正在成为新的工程范式:与其为每个任务造轮子,不如把几个通用能力块组合起来——每块都站在海量数据的肩膀上。

6 多模态大模型:从分数到对话

沿着"语言进入质检"的路再往前一步,是把整个大语言模型请进来。AnomalyGPT(AAAI 2024)把工业异常检测模块接进多模态大模型:图像编码器负责看,LLM 负责想和说。于是质检系统第一次不止输出一个分数,还能回答问题:

一段对话

质检员:这个零件有什么问题?
模型:图像左上角区域检测到一道约 3mm 的细长划痕,置信度较高;其余表面未见明显异常。建议对该区域复检。

别小看这一步。传统方法给出"异常分 0.87 + 一张热力图"之后,仍然需要工程师去解读:是什么缺陷?严不严重?要不要停线?解释,是检测报告里隐藏的人力成本。多模态大模型把这部分也吃掉了:定位、描述、严重程度评估、处置建议,一句话问出来。而且对话是双向的——还可以追问"和上一批相比呢?"、"这种划痕常见的成因是什么?"。

工业质检的输出形态,正在从"分数"走向"对话"。这条线刚刚开始,但方向已经清晰:检测模型负责看得准,语言模型负责说得清。

7 冷静一页:zero-shot 的真实水位

讲了一整课的"游戏规则改写",这一页泼点冷水——工程决策需要知道水位到底在哪。

数字说话:在 MVTec AD 基准上,WinCLIP 的零样本图像级 AUROC 约在 91~95% 区间;而第 8 课的 PatchCore,用几百张正常样本能稳定做到 99%+。四到八个点的差距,在误检率上可能是数倍的差别——零样本方法目前打不过喂饱了正常样本的特征嵌入方法,这个结论到今天依然成立。

难啃的硬骨头也很明确:

  • 细粒度纹理缺陷:布料上织错的一根线、金属表面轻微的橘皮纹——这类缺陷在语言里很难描述清楚,CLIP 的语义空间也分辨不了这么细的粒度;
  • 语义模糊的"缺陷":同样一道印痕,A 产品算合格、B 产品算报废——"算不算缺陷"取决于工艺标准,而工艺标准写不进一句通用的 prompt。
务实姿势

把零样本当冷启动工具,而不是终点:产线第一天,用 WinCLIP / AnomalyCLIP 零样本顶上,先把最明显的缺陷拦住;攒到几十张正常样本,就切换到 PatchCore 这类特征嵌入方法,把精度提到工业水位。两者之间还有一座桥:few-shot(少样本)——WinCLIP 的少样本版本只要 1~4 张正常参考图,分数就能明显上一个台阶。"零样本兜底、少样本过渡、够样本切主力"——这条选型路线,下一课的决策树会正式画出来。

✓ 自我检验

四道题,检查本课的核心概念是否立住了。

Q1 · CLIP 在 4 亿图文对上的训练目标是?
✔ 正确。§1 的"连连看":一个 batch 里 N 对图文形成 N×N 相似度矩阵,InfoNCE(softmax + 交叉熵)让对角线上的配对胜出——配对拉近、错配推远,图和文因此住进同一个语义空间。
✘ 回看 §1 的训练目标:CLIP 没有类别标签,监督信号就是"哪张图配哪句话"这个配对关系本身——配对拉近、错配推远,这就是对比学习。
Q2 · zero-shot 分类时,"分类器"从哪里来?
✔ 正确。§1 结尾和 §2 的模拟器演示的正是这件事:每句 prompt 的文本向量充当类别中心,图像向量和它们比余弦、做 softmax——分类器是"写"出来的,不是训出来的,换类别只需改字符串。
✘ 回看 §1 结尾与 §2 的模拟器:全程没有任何训练与微调,比较的也不是像素,而是编码器输出的语义向量——四句话就是四个分类器。
Q3 · WinCLIP 的异常分数是怎么算出来的?
✔ 正确。§3 第一板斧:normal 组与 anomaly 组两队 prompt 对垒,图像和两组的相似度做 softmax,anomaly 侧的概率就是异常分——练习 TODO 5 实现的就是它的两句话最小版。
✘ 最近邻距离是第 8 课 PatchCore 的做法(需要正常样本库),数像素则需要先有分割结果。回看 §3:WinCLIP 的异常分来自 normal / anomaly 两组 prompt 的 softmax 对垒,零样本、零库存。
Q4 · AnomalyCLIP 相对 WinCLIP 的核心改进是什么?
✔ 正确。§4:prompt 从手写英文变成可被梯度更新的嵌入向量,而且只学"正常/异常"两个抽象概念、不绑定具体物体——辅助数据上训一次,对没见过的产品依然零样本可用,措辞敏感问题从根上消失。
✘ 回看 §4:AnomalyCLIP 动的是文本这一侧——手写 prompt 措辞敏感、要为每类产品想词,于是把 prompt 换成可学习的 object-agnostic 向量;编码器本身是冻结的,文本也没有被抛弃。

Learning Transferable Visual Models From Natural Language Supervision(CLIP)
OpenAI · ICML 2021 · arXiv 2103.00020
CLIP 原论文:4 亿图文对 + 对比学习,让图像和语言住进同一个向量空间。§1 的全部内容出自这里;方法图(Figure 1)一张图讲完双塔与相似度矩阵,值得反复看。
WinCLIP: Zero-/Few-Shot Anomaly Classification and Segmentation
CVPR 2023 · arXiv 2303.14814
零/少样本缺陷检测代表作:两组 prompt 对垒 + prompt ensemble + 多尺度滑窗定位(§3 的三板斧)。文中的 prompt 模板列表可以直接抄来用。
AnomalyCLIP: Object-agnostic Prompt Learning for Zero-shot Anomaly Detection
ICLR 2024 · arXiv 2310.18961
把手写 prompt 换成可学习的 object-agnostic prompt 向量(§4):辅助数据上训一次,在 17 个跨领域数据集上零样本泛化,措辞工程从此退场。
Segment Anything(SAM)
Meta AI · ICCV 2023 · arXiv 2304.02643
"万物分割"基础模型:1100 万张图、11 亿个 mask 训出的可提示分割(§5)。点/框提示 → 精确轮廓,是缺陷检测流水线里负责精修 mask 的那块乐高。
AnomalyGPT: Detecting Industrial Anomalies Using Large Vision-Language Models
AAAI 2024 · arXiv 2308.15366
把异常检测接进多模态大模型(§6):不止给分数,还能用自然语言回答"这个零件哪里有问题"。工业质检从"分数"走向"对话"的起点。

✎ 配套代码练习

exercise.py:亲手实现 zero-shot 缺陷判定

本课目录下的 exercise.py 用纯 Python(只 import math)把 §1-§3 的推理机制完整走一遍。运行 python exercise.py,完成 5 个递进的 TODO:

  1. TODO 1 · 点积 dot —— 一切相似度的原材料(对应 §1)
  2. TODO 2 · 余弦相似度 cosine_sim —— CLIP 空间里的那把"距离尺"(对应 §1)
  3. TODO 3 · 带温度的 softmax —— 把相似度放大成概率,亲手验证"温度越低,分布越尖"(对应 §2)
  4. TODO 4 · clip_zero_shot —— 串起前三步,完成一次完整的 zero-shot 分类(对应 §2)
  5. TODO 5 · anomaly_probability —— normal / damaged 两句 prompt 对垒打异常分,一个两句话的最小 WinCLIP(对应 §3)

做完 TODO 5 你会看到:同一段代码,不改任何参数,既判对了完好盘、也判对了划痕盘——因为"分类器"只是两句话。难度 ⭐⭐,适合边玩 §2 的模拟器边写。
