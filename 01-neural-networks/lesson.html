缺陷检测课程 · 第 01 课

神经网络是怎么学会的

从一个神经元出发,弄懂"学习"的全部机制:前向计算、损失、梯度下降、反向传播 —— 之后所有缺陷检测方法都建立在这一课之上。

1 "学习"到底是什么

场景

一家轴承厂的质检老师傅,看一眼零件表面就能说出"这个有划痕,不合格"。他没背过任何规则手册——他只是看过几万个零件,好的坏的都见过,经验自己长出来了。

现在我们想让计算机做同样的事:给它看零件的照片,它输出"合格"或"有缺陷"。整个缺陷检测领域,本质上都在解决这一件事。

先把问题翻译成数学语言。一张照片对计算机来说就是一堆数字(每个像素的亮度值),"合格/有缺陷"也可以用数字表示(比如 0 和 1)。所以我们要找的其实是一个函数:输入一堆数字,输出一个判断。

f( 图像的像素值 ) → 0(合格) 或 1(有缺陷)

问题是:这个函数长什么样,没有人写得出来。"划痕"在像素层面可能是几千种不同的数字组合,手写规则(比如"如果某处像素比周围暗 30 就算划痕")在真实产线上会被光照变化、纹理差异、位置偏移打得溃不成军——上世纪的传统机器视觉走的就是这条路,维护规则的成本极高。

深度学习换了一个思路,这个思路是本课程的第一块基石:

核心认知

不要手写函数,而是搭一个带有大量"可调旋钮"的函数模板,然后用数据自动调这些旋钮。这些旋钮叫参数(parameters),自动调旋钮的过程就叫训练(training),也就是"学习"。

神经网络就是那个"函数模板"。它的表达能力足够强,几乎可以逼近任何函数;它的参数(现代网络里有几百万到几十亿个)决定了它具体表示哪一个函数。这一课我们要回答两个问题:

  • 这个函数模板长什么样?(§2-§4:神经元、激活函数、多层网络)
  • 旋钮是怎么被自动调好的?(§5-§8:损失、梯度下降、反向传播、训练循环)

2 最小单元:一个神经元

神经网络由大量结构相同的小单元堆成,这个小单元叫神经元(neuron)。它做的事情简单到可以用一行算式写完:把每个输入乘上一个权重,加起来,再加一个偏置。

z = w₁·x₁ + w₂·x₂ + … + wₙ·xₙ + b

逐个拆开这几个符号——它们会贯穿整门课程:

  • x₁ … xₙ(输入):喂给神经元的数字。可以是像素值,也可以是别的神经元的输出。
  • w₁ … wₙ(权重,weight):每个输入的"重要程度"。权重大,这个输入对结果影响大;权重为负,这个输入起反向作用。权重是可以调的旋钮。
  • b(偏置,bias):一个整体的"门槛调节器"。它决定加权和要多大,神经元才倾向于给出高输出。偏置也是旋钮。
  • z(加权和):神经元的原始打分,随后还要经过一步激活函数(§3)。

用质检的例子把它具象化。假设我们手工提取了零件的两个特征:x₁ = 尺寸偏差、x₂ = 表面粗糙度(都归一化到 0~1,越大越糟糕)。一个判断"是否为缺陷件"的神经元可能学到 w₁ 和 w₂ 都是正数(两个特征越大越可疑),b 是负数(把门槛抬高,轻微异常不算缺陷)。加权和 z 超过 0,就倾向于判"缺陷"。

在二维输入下,这件事有一个非常直观的几何解释:w₁·x₁ + w₂·x₂ + b = 0 是平面上的一条直线,神经元就是用这条直线把平面切成两半——一侧判合格,一侧判缺陷。调整权重就是旋转这条线,调整偏置就是平移这条线。

要点

一个神经元 = 一条直线(高维时是一个超平面)= 一次线性判断。它很弱,只能处理"一刀切得开"的问题。神经网络的全部威力来自把很多这样的弱判断组合起来——但在组合之前,还缺一个关键零件:激活函数。

3 激活函数:非线性从哪来

先看一个容易被跳过、但必须弄明白的问题:如果把很多神经元直接一层层连起来,不加任何处理,会发生什么?

答案是:白连。线性函数套线性函数,结果仍然是线性函数。第一层算 z₁ = W₁x + b₁,第二层算 z₂ = W₂z₁ + b₂,代入展开:z₂ = (W₂W₁)x + (W₂b₁ + b₂)——这就是一个新的 一层 线性函数,权重是 W₂W₁,偏置是 W₂b₁+b₂。叠一百层,依然等价于一层,依然只能画一条直线。而"划痕 vs 正常纹理"显然不是一条直线能切开的问题。

解决办法:在每个神经元的加权和 z 后面,套一个非线性的函数,叫激活函数(activation function):

a = g(z) = g(w₁x₁ + w₂x₂ + … + b) # g 是非线性的,a 叫激活值

有了这一步,"线性套线性"就变成了"线性 → 弯折 → 线性 → 弯折 → …",复合出来的函数可以弯曲、折叠,表达任意复杂的边界。两个最常用的激活函数:

📈 两个最重要的激活函数

Sigmoid:σ(z) = 1 / (1 + e⁻ᶻ)

把任意实数压缩到 (0, 1) 之间,天然适合表示"概率"或"开关程度"。

缺点:输入很大或很小时曲线几乎平了(饱和),梯度接近 0,深层网络里会导致学习信号消失。现在主要用在输出层表示概率。

ReLU:g(z) = max(0, z)

小于 0 一律输出 0,大于 0 原样通过。简单、计算快、正区间梯度恒为 1,不饱和。

是现代 CNN 中隐藏层的默认选择。下一课的卷积网络里你会到处见到它。

这个结构为什么强?两个角度:

几何角度:§2 里一个神经元只能切一刀。隐藏层里 10 个神经元就是 10 刀,下一层再把这些"刀"的结果组合(比如"第 1 刀的左边 且 第 3 刀的上边"),就能围出任意形状的区域。理论上,只要隐藏层足够宽,两层网络就能以任意精度逼近任意连续函数——这就是通用近似定理。它告诉我们"函数模板"的表达能力是够的,剩下的问题只是怎么调参数。

特征角度(对后面的课程更重要):每一层都在把上一层的表示重新组合成更抽象的表示。以图像为例,训练好的网络里普遍观察到这样的层次:浅层神经元响应边缘和颜色斑块 → 中层组合出角点、纹理 → 深层组合出零件轮廓、缺陷形态这类语义概念。

埋一颗种子

"深层特征是逐层组合出来的、带语义的表示"——记住这句话。第 8 课你会看到,当今工业界最主流的缺陷检测方法(PaDiM、PatchCore)压根不训练检测模型,而是直接借用一个在海量自然图像上预训练好的网络的中间层特征。为什么借来的特征能用?根源就在这里。

到此为止,"函数模板"交代完了:它就是一摞交替的"线性变换 + 非线性弯折",全部行为由参数(所有 W 和 b)决定。接下来是本课的下半场:参数是怎么被自动调好的。

5 损失函数:给"错得多离谱"定价

想自动调参数,第一步是把"预测得好不好"变成一个可以计算的数字。这个数字叫损失(loss),计算它的函数叫损失函数。约定:损失越小,预测越好。于是"学习"就被转化成一个纯数学问题——找到让损失最小的那组参数,也就是最优化问题。

回归任务:均方误差(MSE)

如果网络输出的是连续数值(比如预测划痕的长度),最自然的损失是预测值与真实值之差的平方,再对所有样本取平均:

L = (1/N) · Σ (ŷᵢ − yᵢ)² # ŷ 是预测,y 是真实答案

平方有两个作用:抹掉正负号(偏高偏低都算错),并且放大大错误——错 2 的代价是错 1 的 4 倍,迫使模型优先修正离谱的预测。

分类任务:交叉熵(cross-entropy)

如果网络输出的是概率(比如"这个零件是缺陷件的概率为 0.9"),用交叉熵。对一个真实标签为 y∈{0,1} 的样本:

L = −[ y·log(ŷ) + (1−y)·log(1−ŷ) ]

不用被公式吓到,它表达的直觉只有一句话:惩罚"自信的错误"。真实是缺陷件(y=1)而模型说 ŷ=0.9,损失 −log(0.9)≈0.105,很小;模型说 ŷ=0.01(自信地判成合格),损失 −log(0.01)≈4.6,巨大。越自信地错,罚得越狠——这正是我们希望质检系统具有的品格。

为什么这很重要

损失函数是你向模型表达目标的唯一渠道。模型不懂"帮我找缺陷",它只懂"把这个数字弄小"。后面课程里各种方法的差异,很大程度上就是损失函数的差异:第 6 课分割任务用 Dice/Focal 损失对付类别不平衡;第 7 课自编码器用重构误差当损失;第 12 课 CLIP 用对比损失把图像和文字拉到同一空间。看懂一个方法,先看它的损失在优化什么。

6 梯度下降:往哪调,调多少

目标明确了:调整参数,让损失变小。但一个现代网络有百万级参数,不可能瞎试。我们需要知道:每个参数往哪个方向动、动多少,损失下降得最快?微积分给出了答案。

先退到最简单的情形:只有一个参数 w。损失 L(w) 就是一条曲线。曲线上任意一点的导数(斜率)告诉我们:w 增大一点点,L 会怎么变。斜率为正 → 往右走损失上升,所以应该往左走;斜率为负 → 应该往右走。总结成一条规则:沿着斜率的反方向走。

w ← w − η · dL/dw # η(eta)是学习率:每一步迈多大

参数有很多个时,把每个参数的偏导数收集成一个向量,这个向量叫梯度(gradient),记作 ∇L。梯度指向损失上升最快的方向,于是负梯度方向就是下降最快的方向。沿负梯度反复小步走,就是梯度下降(gradient descent)——整个深度学习的发动机。

学习率 η 是你亲手设置的(这类参数叫超参数),它的取值极其关键。亲手感受一下:

要点:局部极小值与随机性

你可能注意到演示曲线上有个小坑:小球有时会停在不是最低点的坑里,这叫局部极小值。真实训练中还有两个补充:① 实践中不用全部数据算梯度,而是每次随机抽一小批(mini-batch),得到的梯度带噪声,这叫随机梯度下降(SGD),噪声反而帮助跳出小坑;② 现代常用的 Adam 等优化器给每个参数自适应调步长,是 SGD 的改良款。在高维空间里,局部极小值实际造成的麻烦比想象中小。

7 反向传播:算出每个参数的"责任"

梯度下降需要知道损失对每一个参数的导数。难点在于:深层网络里,一个浅层权重要经过后面所有层才影响到损失,这个导数怎么算?挨个参数用"微调一下看损失变多少"的笨办法,一百万个参数就要跑一百万次前向计算,完全不可行。

反向传播(backpropagation)是高效解法,它的数学内核只有一个:链式法则——复合函数的导数等于沿路各段导数的乘积:

若 L 依赖 a,a 依赖 z,z 依赖 w,则: dL/dw = dL/da · da/dz · dz/dw # 影响力沿链条逐段相乘

关键的观察是:相邻参数的链条大量重叠。第 3 层某权重的链条,是第 5 层某权重链条的延长。所以从损失出发从后往前算,每层把"损失对本层输出的导数"算好传给前一层,前一层接着用,任何中间量都只算一次。一次前向 + 一次反向,所有参数的梯度全部到手,成本只相当于两次前向计算。

8 拼装:完整的训练循环

把 §5-§7 的零件按顺序接起来,就是所有深度学习训练的通用骨架——不管是分类网络、分割网络还是第 7 课的自编码器,训练时都在跑这四步循环:

STEP 1
前向传播
取一小批样本
过网络得到预测 ŷ
→
STEP 2
计算损失
用损失函数对比
ŷ 和真实答案 y
→
STEP 3
反向传播
链式法则算出
所有参数的梯度
→
STEP 4
更新参数
w ← w − η·∇L
回到 STEP 1

两个高频术语在这里顺便定义,第 3 课会展开:每次循环用的那一小批样本叫一个 batch;全部训练数据完整过一遍叫一个 epoch。训练通常要跑几十到几百个 epoch。

用伪代码写出来(和你在练习里要实现的东西一一对应):

for epoch in 1..N: for batch in 训练数据: y_hat = model.forward(batch.x) # STEP 1 前向 loss = loss_fn(y_hat, batch.y) # STEP 2 损失 grads = backward(loss) # STEP 3 反向 params = params - lr * grads # STEP 4 更新

本课到此,你已经拥有了理解后续一切内容的最小完备基础:网络 = 参数化的函数模板;训练 = 用梯度下降最小化损失;反向传播 = 高效算梯度的手段。下一课我们解决一个现实问题:图像有几十万个像素,直接接全连接网络参数量爆炸且浪费结构信息——卷积神经网络如何优雅地解决它。

✓ 自我检验

四道题,检查本课的核心概念是否真的立住了。

Q1 · 如果把网络里所有激活函数都去掉,一个 100 层的网络会变成什么?
✔ 正确。线性变换的复合仍是线性变换(W₂(W₁x+b₁)+b₂ 可合并成一层),深度完全失效。非线性激活是深度网络表达能力的来源。
✘ 再想想 §3 开头的推导:线性套线性还是线性,100 层会坍缩成等价的 1 层。
Q2 · 训练时把学习率设得过大,最可能观察到的现象是?
✔ 正确。步子太大会一步迈过谷底、在两侧来回弹,如 §6 实验 ② 所见,严重时直接发散(损失变成 NaN 是实践中的经典症状)。
✘ 回到 §6 的交互演示,把 η 拉到 2.5 以上再走几步,观察小球和损失的变化。
Q3 · 反向传播算法的本质作用是?
✔ 正确。它只负责"高效算梯度",拿到梯度后还是交给梯度下降去更新参数。一次前向+一次反向,百万参数的梯度全部到手。
✘ 注意区分"学习原理"(梯度下降)和"计算手段"(反向传播),见 §7 结尾的要点框。
Q4 · 一个缺陷分类模型对某个真实有缺陷的零件(y=1)输出 ŷ=0.02(自信地判为合格)。用交叉熵损失,这个样本的损失会?
✔ 正确。L = −log(0.02) ≈ 3.9,而 ŷ=0.4 时只有 −log(0.4) ≈ 0.92。越自信地漏检,罚得越狠——这对"漏检代价极高"的工业质检尤其合理。
✘ 代入公式算一下:y=1 时 L = −log(ŷ),ŷ 越接近 0,−log(ŷ) 越趋向无穷大。见 §5。
