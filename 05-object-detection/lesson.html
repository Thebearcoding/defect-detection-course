有监督路线 I:目标检测

当你有标注得起的缺陷框时,检测是最直接的路——本课把"框是怎么被找出来的"拆到原子:一把叫 IoU 的尺子、一张叫 anchor 的框网、一次叫 NMS 的去重,以及把这一切串起来的评分逻辑。

站上第 4 课画出的那张地图,先确认位置,再出发:

1 任务定义:输出一张"结果清单"

先把任务钉死。目标检测(object detection)的输入是一张图像,输出是一张"结果清单":图里每找到一个目标,清单里就多一行,每行 6 个数——

输入:一张 640×480 的钢材表面图 输出:[ (x1= 88, y1= 40, x2=156, y2= 96, 类别=夹杂, 置信度=0.91), (x1=310, y1=205, x2=420, y2=260, 类别=划痕, 置信度=0.84), (x1=500, y1=380, x2=548, y2=430, 类别=麻点, 置信度=0.57), ] # 下一张图可能是 0 行,也可能是 30 行 —— 数量不定

三个组成部分拆开看:

  • 框(bounding box):用左上角 (x1, y1) 和右下角 (x2, y2) 两个点圈住目标。本课与配套练习里的所有框,都统一用 [x1, y1, x2, y2] 这个约定;
  • 类别:框里是什么(划痕/麻点/夹杂……)——这就是第 1 课的分类;
  • 置信度:网络对"这个框里真有这个目标"的把握,0 到 1 的分数。§5 的去重、§6 的评分,全都围着它转。

它和分类的本质区别在于输出的形状。分类的输出维度是固定的——1000 类就是 1000 个数;检测的输出却是不定数量的结构化对象:同一条产线,这张钢板 0 个缺陷,下一张可能 30 个。而神经网络天生只会输出固定尺寸的张量。怎么用固定的输出表示数量不定的框?这个矛盾是检测所有结构设计的总源头——§3 的 anchor 就是对它的回答。

标注格式一句话说完:训练数据就是"每张图 + 一份框清单",清单里每个缺陷一行 (类别, x1, y1, x2, y2)——用 LabelImg 之类的工具在图上拉框即得(VOC、COCO 是两种最常见的存储格式)。

2 IoU:两个框的重叠度量

有了预测框和真值框,第一个问题是:怎么衡量"预测框画得准不准"?中心点距离?面积之差?都不稳——框偏一点、大一圈,这些量的表现完全不同。检测领域的标准答案是交并比(IoU,Intersection over Union):

IoU(A, B) = 交集面积 / 并集面积 # 范围 [0, 1]:完全不相交 = 0,完全重合 = 1

它同时惩罚"没盖住"(交集小)和"画太大"(并集大),而且对框的绝对尺寸不敏感——大目标小目标一视同仁。手算一遍,体感立刻建立:

A = [0, 0, 10, 10] B = [5, 5, 15, 15] 交集 = [5, 5, 10, 10] → 宽 5 × 高 5 = 25 并集 = 面积A + 面积B − 交集 = 100 + 100 − 25 = 175 IoU = 25 / 175 = 1/7 ≈ 0.143 # 看着重叠不少?其实连七分之一都不到
📐 交互:把橙框推向绿框,看 IoU 怎么变
绿色是真值框 GT,位置固定;拖动两个滑块,水平/垂直移动橙色预测框,蓝色区域是两框的交集。试三件事:① 推到完全重合,IoU = 1;② 拉到完全分离,IoU = 0;③ 找到 IoU 恰好越过 0.5"及格线"的临界位置——注意越线前后进度条的变色。

那条 0.5 的"及格线"值得单独记住:它是 PASCAL VOC 确立的经典判定阈值——预测框与真值框 IoU ≥ 0.5 才算"命中"。往后你会看到,训练时的正负样本分配(§3)、NMS 的去重判据(§5)、评测时的 TP/FP 判定(§6),用的都是 IoU 这同一把尺子,只是阈值各有取法(COCO 评测甚至同时取 0.5 到 0.95 十档再平均)。

3 从滑窗到 anchor:找框变成分类 + 回归

朴素方案:滑窗,以及它为什么不行

最直觉的检测方案是把它退化成"无数次分类":拿一个窗口在图上逐位置滑动,每个位置裁下来问分类器"这是不是缺陷";缺陷有大有小、有扁有长,还得每种尺寸、每种长宽比都各滑一遍。位置数 × 尺寸数 × 长宽比数,一张 400×400 的图轻松滑出上百万个窗口,每个窗口都独立跑一次网络——天文数字,产线上根本没法用。

anchor:把窗口"预铺"在特征图上

anchor 的思想是反着来:不裁图、不重复跑网络,而是在特征图的每个位置,预先铺 k 个不同尺寸、不同长宽比的参考框——anchor(锚框)。第 2 课说过,特征图每个格子对应原图的一片感受野,所以这相当于在原图上均匀撒下一张覆盖各种大小形状的"框网"。然后,网络对每个 anchor 只需要回答两件事:

  • 分数(分类):这个 anchor 罩住的区域里,有没有目标?
  • 微调量(回归):目标的真实框相对这个 anchor,要平移多少、缩放多少?——4 个数 (dx, dy, dw, dh)。anchor 只要和目标大致沾边,精确的框由回归量修出来。

训练时 anchor 怎么"领任务":正负样本分配

训练时,哪个 anchor 该学"有目标"?用 §2 的尺子量:与某个真值框 IoU 超过 0.5 的 anchor 记为正样本——它负责这个目标,既要把分数打高,也要学会输出正确的微调量;与所有真值框都几乎不沾边的记为负样本——只需学会打低分(背景);夹在中间的模糊地带通常直接忽略,不参与损失。配套练习的 TODO 2 会让你亲手做一次这个分配。

这一步完成了本课最关键的化归

盘点 anchor 换来了什么:① 所有 anchor 的分数和微调量由同一次骨干前向顺便算出,卷积天然共享了滑窗的重复计算;② §1 留下的"输出数量不定"难题消失了——网络输出永远是"每个 anchor 5 个数"的固定张量,数量不定的只是高分 anchor 有几个;③ 最重要的:"在图里找框"被彻底改写成了第 1 课你就会的分类 + 回归。深度学习攻克新任务的套路从来如此:不发明新数学,而是把新任务改写成老任务。

4 两条流派:two-stage 与 one-stage

anchor 解决了"候选从哪来",接下来的分岔只有一个问题:要不要对候选再精修一轮?由此分出检测的两大流派。

two-stage:先海选,再精修(Faster R-CNN)

第一阶段,RPN(区域建议网络)在特征图上按 §3 的方式给所有 anchor 打分、回归,只留下几百个最像"有东西"的候选框;第二阶段,把每个候选框对应的特征单独抠出来,再做一次更精细的分类(具体是哪类)和框回归(二次微调)。两轮筛选、两次回归,框更准、误报更少——代价是第二阶段要对每个候选逐个计算,速度提不上去。

one-stage:一次前向,全部出炉(YOLO)

YOLO(You Only Look Once,名字就是宣言)干脆取消第二阶段。它的网格思想值得单独讲透:

把整张图划成 S×S 的网格(论文里是 7×7)。分工规则只有一句话:目标的中心点落在哪个格子,就由哪个格子负责预测它。每个格子直接输出 B 个框(坐标 + 置信度)和一份类别概率;整张图一次前向,S×S 个格子的所有预测同时出炉,后面只接一个 NMS(§5)收尾。它快的根本原因不是网络小,而是流程里压根没有"逐候选精修"这一步。

顺带把两派的关系说清:网格与 anchor 并不互斥——"格子"本质就是特征图上的位置,从 YOLOv2 起每个格子上也铺了几种形状的 anchor;SSD 则更进一步,在多个尺度的特征图上都铺 anchor(它管这叫 default box)。两派真正的分水岭只有一个:有没有第二阶段。

two-stage(Faster R-CNN 系)

速度:慢——候选要逐个精修,两阶段串行。

精度:同代对比更高,小目标、密集目标尤其稳。

适用场景:离线抽检、复检仲裁这类"宁慢勿漏"的场合。

one-stage(YOLO / SSD 系)

速度:快——一次前向直接出全部预测,能跟上实时产线。

精度:早期略逊于 two-stage,现代版本差距已经很小。

适用场景:在线全检、边缘设备部署这类"卡节拍"的场合。

5 NMS:一个目标只留一个框

无论哪派,网络的原始输出都有同一个毛病:anchor(或网格)铺得密,同一个缺陷周围会有一堆 anchor 同时喊"我这有目标"——于是一个目标顶着好几个高度重叠、分数都不低的框。评测时一个真值只认一个预测,多出来的全算误报,必须去重。这就是 NMS(Non-Maximum Suppression,非极大值抑制),检测流水线的最后一步。算法本体只有三行:

1. 把所有候选框按分数从高到低排序,放进候选池 2. 取池中最高分的框保留;把池里与它 IoU > 阈值(常取 0.5)的框全部删掉 3. 重复第 2 步,直到候选池取空 # 名字直译:"非极大值"(不是局部最高分的框)被"抑制"(删掉)
🧹 交互:NMS 步进演示——从 6 个框到 3 个框
网络在左上和右侧两处目标附近各输出了一簇重叠框(A/B/C 与 D/E),右下另有一个独立低分框 F,分数已标在框上。点「下一步」,亲眼看贪心去重的每一步:排序 → 保留最高分(绿)→ 抑制与它 IoU > 0.5 的框(灰色虚线)→ 重复。特别注意 F 的命运。

看完演示,把判据抠死:一个框被抑制,必须同时满足两个条件——与某个已保留框的 IoU 超过阈值,且它自己的分数更低。F 只有 0.45 分却活到了最后,因为它不和任何已保留框重叠;C 有 0.70 分却被删掉,因为它撞上了 0.92 分的 A。NMS 淘汰的从来不是"低分框",而是"重复框"。

两个工程注脚:① NMS 是纯后处理,不参与训练,就是网络外面的一段普通代码(练习 TODO 3 你会亲手写出它);② 里面的 IoU 阈值是个手工旋钮——调太低,挨得近的两个真缺陷会被误杀成一个(密集小缺陷场景要格外小心);调太高,重复框删不干净、误报上升。§7 还会回到这个痛点。

6 检测的评分:mAP 直觉

模型输出经过 NMS,得到最终预测。最后一个问题:怎么给一个检测器打总分?难点在于每个预测框带着置信度,卡不同的置信度阈值,表现完全不同——阈值高,报得少而准(精确率高、召回率低);阈值低,报得多而全(召回率高、精确率低)。盯着任何一个阈值下的 P 或 R 都有失偏颇。mAP 的思路是:不选阈值,把所有阈值下的表现一次性积分。

流程四步(其中的判定规则,正是练习 TODO 4 要实现的):

  1. 把全部预测框按置信度从高到低排序;
  2. 逐个判定:与某个尚未被认领的真值框 IoU ≥ 0.5 → 记 TP,并占用该真值(防止一个真值被重复领功);否则记 FP;
  3. 每走一步,算一对累计(精确率, 召回率),得到 PR 曲线上的一个点;
  4. 把点连成 PR 曲线,曲线下面积就是这一类的 AP;所有类别取平均,就是 mAP。
例:2 个真值框,3 个预测框,按置信度降序逐个判定 排名 置信度 判定 累计精确率 P 累计召回率 R 1 0.90 TP 1/1 = 1.00 1/2 = 0.50 2 0.80 FP 1/2 = 0.50 1/2 = 0.50 # 它瞄的真值已被第 1 名占用 3 0.70 TP 2/3 ≈ 0.67 2/2 = 1.00 # 每行给出一个 (R, P) 点 → 连成 PR 曲线 → 曲线下面积 = AP → 各类平均 = mAP

为什么一个数能同时反映"准"和"全"?因为曲线下面积大,意味着在召回率从 0 爬到 1 的全过程中,精确率都保持得住。漏检多的检测器,召回率早早到顶,曲线右边直接缺一块,面积上不去;误报多的检测器,高置信度段就混进 FP,整条曲线被压矮。想拿高 mAP,只能又准又全,两头都骗不过去。

接上第 4 课的指标谱系:mAP 是有监督检测的通用总分;而后面无监督异常检测(第 7 课起)常用的 AUROC / PRO 是另一套逻辑,到时候对照着看,你会发现"按分数排序、扫过所有阈值"这个母思想是共通的。

7 用在缺陷检测上:什么时候选它,坑在哪

什么时候选检测?

  • 缺陷类别固定、可枚举:划痕、麻点、夹杂、缺件……类别清单事先写得出来,每类都能攒出足够样本;
  • 标注预算撑得起:每类几百上千个框的标注量。画框比描像素轮廓便宜得多——这是它相对第 6 课语义分割的成本优势;
  • 要计数、要定位:PCB 上查元件缺失、错件,要"哪个位置少了什么"的结论;钢材表面缺陷的经典数据集 NEU-DET(热轧钢带六类缺陷)走的就是这条检测路线。

三个工程痛点

  • 小目标:缺陷可能只占几个像素,映到深层特征图上不足一个格子,anchor 与它的 IoU 天生偏低,§3 的正样本分配都凑不齐,想学都没得学。标准解法是 FPN 多尺度特征——把深层语义自顶向下送回高分辨率的浅层,在多个尺度上同时预测。这里先埋一句伏笔,原文在下方。
  • 极端类别不平衡:一张图几千个 anchor,正样本可能只有个位数,损失被海量"背景"支配;不同缺陷类别之间的样本量也常差几个量级——常见病是模型学会了"全报背景"。
  • 标注一致性:"划痕从哪算到哪"、两道相邻划痕算一个框还是两个,不同标注员画出的框可能差很远。IoU 阈值卡在 0.5 时,这种标注抖动会直接变成训练与评测里的噪声。
📖 小目标伏笔的原文:Feature Pyramid Networks(FPN)——用极小的代价给每个尺度都配上"深层语义 + 高分辨率"的特征,现代检测器几乎人手一份的标准部件。
什么时候不选它——回到第 4 课的光谱

检测的前提是:缺陷长什么样可以被预先枚举,并且标注得起。两个条件缺任何一个——缺陷形态开放(什么怪样都可能出现)、或者根本攒不齐带框标注——全监督检测就不是正确的起点,该沿着第 4 课的光谱往另一端走,去第 7-11 课的无监督分支:只用正常样本建模,"不认识的就是异常"。而下一课,先看全监督这条支线的另一站:当"框"不够细、需要像素级轮廓时,怎么做语义分割。

✓ 自我检验

四道题,检查本课的核心概念是否立住了。

Q1 · IoU = 交集面积 ÷ 并集面积。两个完全相同的框,IoU 等于多少?
✔ 正确。完全重合时,交集和并集是同一块区域,比值恒为 1——这是 IoU 的上限,与框多大无关。去 §2 的交互里把橙框推到与绿框完全重合,亲眼确认一次。
✘ 回看 §2 的定义:IoU = 交集 ÷ 并集。两框完全重合时,交集和并集就是同一块区域,比值只能是 1,和面积大小无关。
Q2 · anchor 机制最核心的贡献,是把"在图里找框"转化成了什么问题?
✔ 正确。§3 的化归:anchor 预铺之后,网络只需对每个 anchor 输出 1 个分数和 4 个微调量——检测被拆回了第 1 课就会的分类 + 回归两个原子操作,"输出数量不定"的难题也随之消失。
✘ 回看 §3 结尾的 insight:anchor 的全部意义,是把找框改写成"每个 anchor 的分类 + 回归"。逐像素的分割是第 6 课的事,重构是第 7 课的事。
Q3 · NMS 决定"抑制"某个候选框,依据的判据是?
✔ 正确。被抑制 = 与已保留框 IoU 超阈值、且分数更低——两个条件缺一不可。§5 演示里的 F 是活证据:0.45 的低分照样保留,因为它不和任何已保留框重叠;0.70 的 C 反而被删,因为它撞上了 0.92 的 A。
✘ 回看 §5 的步进演示:F 分数只有 0.45 却活到最后,C 有 0.70 却被删掉。NMS 淘汰的不是"低分框"或"小框",而是"与更高分的已保留框重叠过多"的重复框。
Q4 · one-stage 检测器(如 YOLO)比 two-stage 快,最根本的原因是?
✔ 正确。§4 的分水岭:two-stage 要对几百个候选逐个做二次分类与回归;one-stage 把这一步整个删掉——所有网格/anchor 的预测在同一次前向里同时出炉,后面只剩一个 NMS 收尾。
✘ 网络大小和输入分辨率都是可调的表面因素,两派都能调。回看 §4:结构性的差别只有一个——有没有对候选逐个精修的第二阶段。YOLO 快,是因为它压根没有这一步。

Faster R-CNN: Towards Real-Time Object Detection with Region Proposal Networks
Ren et al. · NeurIPS 2015 · arXiv 1506.01497(英文)

Redmon et al. · CVPR 2016 · arXiv 1506.02640(英文)

SSD: Single Shot MultiBox Detector
Liu et al. · ECCV 2016 · arXiv 1512.02325(英文)

Feature Pyramid Networks for Object Detection
Lin et al. · CVPR 2017 · arXiv 1612.03144(英文)

Object Detection in 20 Years: A Survey
Zou et al. · 综述 · arXiv 1905.05055(英文)
