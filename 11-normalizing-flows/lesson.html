缺陷检测课程 · 第 11 课

归一化流类方法

给"正常"算一个概率——把复杂分布揉成标准高斯,低概率的样本自己举手。这是无监督家族里最"数学"的一支。

0 快速回顾

第 7-10 课把无监督缺陷检测的四条路线走了一遍。回头看,它们其实都在回答同一个问题——"什么是正常"——只是刻画的方式各不相同,而且都是间接的:

  • 第 7 课 · 重构类:AutoEncoder 只学会重建正常样本,重构差大 = 异常——用"画得像不像"间接刻画正常;
  • 第 8 课 · 嵌入类:把正常样本的预训练 patch 特征建档案(PaDiM 的高斯、PatchCore 的记忆库),新样本离档案远 = 异常——用"距离"间接刻画正常;
  • 第 9 课 · 师生蒸馏:学生只见过正常,师生特征分歧大 = 异常——用"模仿失败"间接刻画正常;
  • 第 10 课 · 合成缺陷:自己造伪缺陷,把无监督变成判别题——干脆绕开"刻画正常",直接学"什么不正常"。

本课直捣黄龙:直接学出正常特征的概率密度 p(x)。有了密度,异常的定义前所未有地干净——p(x) 低的样本就是异常,连"间接"两个字都省了。

1 为什么要密度、为什么难

有了 p(x),异常检测变成一句话

假设我们真的拿到了正常世界的概率密度 p(x)——任给一个样本,它能报出"这个样本在正常世界里出现的可能性有多大"。那么异常检测只剩一步:

异常分数 s(x) = −log p(x) # p(x):x 在"正常世界"里的概率密度 # log:把极小的数变成好比较的负数,把连乘变连加 # 负号:概率越低,分数越高,越像异常 例:p = 0.36 → s ≈ 1.0 # 常见,放行 p = 0.0005 → s ≈ 7.6 # 罕见,报警

和前几课的分数(重构差、马氏距离、师生差)相比,−log p 的阈值第一次有了概率语义:"把出现概率低于万分之一的样本判为异常"是一句人能听懂、能向产线负责人解释的话。统计学里,基于似然的检验在理想条件下就是理论最优的判别方式——所以说这是无监督家族里最优雅的表述。

但高维密度是出了名的难估

麻烦在于,密度估计在高维空间是个经典难题。看两个朴素方案怎么死掉的:

  • 直方图:一维切 10 个格子,数每格的样本数,没问题;两维要 100 格;而第 8 课的 patch 特征是几百维——就算每维只切 10 格,512 维需要 10512 个格子,宇宙里的原子也只有约 1080 个。绝大多数格子永远是空的,"数格子"彻底失效。
  • 核密度估计(在每个样本上放一个小土堆,叠成山):高维空间里任何两点的距离都差不多远,"邻居"的概念失去意义,土堆彼此够不着,连不成山。

这就是维度灾难:样本数量跟不上空间体积的指数爆炸,直接在高维空间"数样本"注定失败。深度学习给出的答案换了个思路——不数样本,学变换。这就是归一化流。

2 流的核心思想:揉面,并记账

归一化流(Normalizing Flow)的策略听起来像变魔术:复杂分布我不会算,但标准高斯我会算——它有解析公式,任何一点的密度抬手就能写出来。那就别硬算复杂分布,而是找一个可逆变换 f,把正常特征的复杂分布"揉"成标准高斯:算不了 x 这边的概率,就把 x 送到高斯那边去查表,再把变形过程中的"体积账"补上。

直觉:橡皮筋上的沙子

想象一根橡皮筋,上面均匀撒了一层沙子。现在把橡皮筋的某几段拉长、另几段压短:拉长的地方,同样多的沙子摊在更长的区间上,变稀了;压短的地方,沙子挤在一起,变密了。沙子总量始终不变(总概率恒为 1),变的只是每一处的"密度"。

所以,想从变形后的密度反推变形前的密度,只需在每一点记下"这里被拉伸/压缩了几倍",按倍数把账补回来。这本拉伸账本,就是下面公式里的雅可比行列式。

log p(x) = log N(f(x)) + log|det Jf(x)| # ─────┬───── ──────┬─────── # 落点项 账本项 # 落点项:x 被 f 揉进高斯空间后落在 z = f(x), # 查标准高斯表:z 离 0 越近,这一项越大 # 账本项:f 在 x 附近对空间的体积缩放——拉伸了记负账、 # 压缩了记正账,保证变形前后概率守恒 # 一维时 |det J| 就是 |f′(x)|:橡皮筋在 x 处的拉伸倍数

这条变量替换公式是全课的灵魂,值得用大白话再念一遍:一个点正常与否,一看它流到高斯空间后落点好不好(落点项),二看变换在它附近有没有大动干戈(账本项),两项相加才是它真实的对数密度。只看落点会被骗——§3 的交互里你会亲眼见到一个"落点很好、账本很差"的反例。

对 f 的两大设计约束

不是随便一个神经网络都能当 f。想让上面的公式可用,f 必须满足两条:

  • ① 可逆:每个 x 唯一对应一个 z、每个 z 也能反推回 x。概率是"搬运"过去的,一一对应才能记账;信息在变换中一点不丢。
  • ② 雅可比行列式好算:一般矩阵求行列式要 O(d³),512 维特征、几十层流,每个样本每层都算一次会把训练拖死。必须把网络设计成"行列式白送"的结构。

经典解法一句话就能说完——coupling layer:把特征切成两半,前一半原样通过、只负责算出缩放和平移参数,去仿射变换后一半。反着做就能精确还原(天然可逆);而且它的雅可比是三角矩阵,行列式 = 对角线元素连乘(白送)。NICE 和 RealNVP 的全部魔法就是这一招,叠几十层、每层换着切分方向,"揉面"的表达力就上来了。

流不是黑魔法

一维时,流干的事就是"参数化的分位数映射"——把数据的累积分布对齐到高斯的累积分布。真实的流只是把这件事搬到几百维特征空间、用几十层 coupling 来做,而且 f 不是手工指定的,是用梯度下降从正常样本里学出来的。原理和你下一节亲手拖的那个动画,一模一样。

3 亲手揉一次:分布变形动画

读数怎么看:正常点 x=+1.60 落在右峰正中,变换后 z≈+0.67,离 0 很近——查高斯表得到高密度,log p≈−1.01;异常点 x=+3.60 在两峰之外的远端,变换后被甩到 z≈+3.81,三个多标准差开外——log p≈−7.63。两者概率差了 e6.6≈700 多倍。没有任何人给异常下过定义,它的低概率自己举了手——这就是密度方法的全部主张。

一个值得多看一眼的地方:两峰之间的谷底(x≈0)也是低概率区(log p≈−4.55)。有趣的是,一维的分位数映射会把谷底的点恰好送到 z≈0 附近——落点看起来非常"正常"!但那一带的变换拉伸得极其厉害(谷底那点样本要被摊开去填高斯的峰顶),§2 公式的账本项会记下一笔大大的负账,把 log p 拉回真实的低值。这就是"落点项 + 账本项,缺一不可"的活例子:只看 z 会被骗,把账算全才是真密度。

真实的流和这个玩具的区别只有规模:特征是几百维而不是一维,变换是几十层 coupling 而不是一次插值,而且 f 是从正常样本里学出来的。原理一模一样。

4 打分与像素级异常图:FastFlow 与 CFLOW

把流用于缺陷检测,训练和推理各一句话。训练:只用正常样本,目标是最大化它们的平均 log p(最大似然)——直觉上,是把密度这块"面团"往正常样本聚集的地方捏,捏得越贴合,正常样本的 log p 越高,而没见过样本的区域密度自然塌下去。推理:算 −log p(x),超过阈值就报警。

训练(只用正常样本): maximize 平均 log p(x) = 平均 [ log N(f(x)) + log|det J| ] # 最大似然 推理: s(x) = −log p(x) # 逐位置算 → 热力图

FastFlow:在特征图上做 2D 流

在像素上直接学流太难(图像分布远比特征分布复杂),FastFlow 的选择是回收第 8 课的资产:在 ImageNet 预训练骨干抽出的 patch 特征图上做流。而且它不把特征图拍平,而是做 2D 流——保留 H×W 的空间结构,每个空间位置的特征向量各自过流、各自算出一个 log p。于是 H×W 个位置就是 H×W 个 log p,拼起来天然就是一张像素级异常热力图,连定位都是白送的,只差最后一步插值放大。

CFLOW-AD:条件流 + 多尺度并联

CFLOW-AD 走另一条路:条件流——把位置编码作为条件输入喂给流,相当于告诉它"这个特征来自图像的哪个位置",同一套流参数就能在不同位置表现出不同的密度(边缘位置的正常纹理和中心位置的本就不同)。再把浅、中、深多个尺度的特征各配一个流并联:浅层高分辨率管小缺陷,深层大视野管大缺陷,结果融合。

两者的共同点比区别更重要:骨干统统冻结——又是第 2 课的姿势③(纯特征提取),要训练的只有轻量的流头,几个 epoch 就收敛。流类方法"最数学",工程上却相当务实:它从不碰"从零训练一个生成模型"这种硬骨头。

5 和其他家族对账

流类方法和第 7、8 课的两条路线渊源最深,放在一张桌上对账:

vs 嵌入类(第 8 课)

同样吃预训练 patch 特征,分歧在"怎么刻画正常"。

PatchCore:存样本、查最近邻——非参数,"档案柜"直观,但要背着记忆库,库越大查得越慢。

流:学一个参数化密度——推理只跑一遍网络,内存小、耗时稳定,不随训练集变大而变慢。

vs 重构类(第 7 课)

AutoEncoder:异常分是重构差,没有概率含义;还受"重构太好"悖论困扰——网络泛化能力强到把缺陷也重建出来,分数就失灵。

流:−log p 有严格概率语义;它压根不重构图像,自然不存在这个悖论。可逆性还保证特征信息一点不丢。

代价在哪

要真的训练:比 PatchCore 的"零训练建库"贵,正常样本也要得更多。

对特征分布形状有隐含假设:轻量流揉不动过于破碎的多峰分布。

超参(层数、耦合方式、尺度选择)比"存档案"多,调试门槛更高。

6 使用边界与工程提示

  • 样本量:PatchCore 几十张正常样本就能建库;流要估出一整个密度,通常几百张起步才稳。样本太少时,最大似然会把密度捏得过分贴合训练集,新的正常样本反而拿低分。
  • 表达力边界:纹理高度多样的类别(花色布料、木纹)在特征空间里是破碎的多峰分布,轻量流头可能"揉不成"高斯;加深流能缓解,但训练成本与过拟合风险同步上升。
  • 阈值标定:−log p 虽有概率语义,但它是特征空间里的密度,数值受骨干、维度、分辨率影响,绝对值并不直接等于"真实世界的概率"。产线上阈值仍要靠验证集标定——第 13 课专门讲这件事。
  • 速度:FastFlow 推理只是一次前向,速度与师生蒸馏同级,快于要查库的 PatchCore(大库场景),满足多数产线节拍。
"最数学"不等于"最好用"

论文里,FastFlow / CFLOW 的 AUROC 与 PatchCore 基本打平(MVTec AD 上都挤在 99% 上下);但工业落地更多选 PatchCore / EfficientAD——建库简单、行为直观、坏了好排查。流类方法真正的差异化卖点是两个:带概率语义的分数(阈值能解释)和小内存、稳定耗时的推理(不背记忆库)。什么产线该为这两个卖点买单?第 13 课的选型决策树见。

✓ 自我检验

四道题,检查本课的核心概念是否立住了。

Q1 · 归一化流方法的异常分数是什么?
✔ 正确。流直接学出正常特征的概率密度 p(x),异常分数 = −log p(x)——低概率样本自己举手(§1)。这也让阈值第一次有了概率语义。
✘ 重构误差是第 7 课、最近邻距离是第 8 课的分数。本课的流直接给出概率密度,分数是 −log p(x)。回看 §1 的公式框。
Q2 · 变量替换公式里的 log|det J| 那一项,在记什么账?
✔ 正确。§2 的橡皮筋:拉伸的地方沙子变稀,密度要按拉伸倍数记账。这一项保证变形前后总概率守恒,和落点项相加才是完整的 log p(x)——§3 谷底点的例子里,全靠它把"落点很好"的假象拉回真实低概率。
✘ 它和参数量、马氏距离都无关。回看 §2 的橡皮筋比喻:log|det J| 是变换的"体积缩放账本",没有它概率就不守恒,只看落点会被骗(§3 谷底点就是反例)。
Q3 · 流对变换 f 的两大设计要求是?
✔ 正确。可逆保证 x 与 z 一一对应、账能记回来;雅可比易算保证 log|det J| 不至于 O(d³) 地拖垮训练。coupling layer 一招同时满足两条:反着做即还原,雅可比是三角阵、行列式白送(§2)。
✘ 深度和参数量是自由度,不是硬约束;流输出的是密度(可以大于 1),不是 0-1 的概率。回看 §2 的"两大设计约束":可逆 + 雅可比行列式好算。
Q4 · FastFlow 为什么"天然"就有像素级异常热力图?
✔ 正确。§4:FastFlow 不拍平特征图,H×W 个位置各自过流、各自出 log p,异常定位是"白送"的,只差一步插值放大——这正是它比"拍平再建模"高明的地方。
✘ FastFlow 不重构图像(那是第 7 课),也不做滑窗分类。回看 §4:2D 流在特征图每个空间位置各自算 log p,热力图天然免费。

NICE: Non-linear Independent Components Estimation
Dinh et al. · arXiv 2014
流模型的开山之作,coupling layer 的起点:一半变量算参数去变换另一半,可逆且雅可比三角。§2 那"一句话"的完整原型,论文本身出奇地好读。
Density estimation using Real NVP
Dinh et al. · ICLR 2017
把 coupling 升级为"缩放 + 平移"的仿射形式,归一化流从此有了标准形态——后续所有缺陷检测流方法用的都是这套积木。
FastFlow: Unsupervised Anomaly Detection and Localization via 2D Normalizing Flows
Yu et al. · arXiv 2021
§4 的主角:在冻结骨干的特征图上做 2D 流,逐位置出 log p,像素级热力图白送,速度快到能上产线——2D 流做缺陷检测的代表作。
CFLOW-AD: Real-Time Unsupervised Anomaly Detection with Localization via Conditional Normalizing Flows
Gudovskiy et al. · WACV 2022
条件流路线:位置编码作条件 + 多尺度并联,同一套流参数在不同位置给出不同密度,兼顾大小缺陷。
CS-Flow: Fully Convolutional Cross-Scale-Flows for Image-based Defect Detection
Rudolph et al. · WACV 2022
跨尺度流:多个分辨率的特征图在流内部互通信息再联合估密度,专攻工业缺陷检测的整图级判定。
